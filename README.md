## Learning Structure

Each lab is documented with:

- **Problem** — What problem are we solving?
- **Solution** — Which cloud service/approach is used?
- **Why** — Why is this solution appropriate?
- **How it works** — The underlying cloud concept
- **Implementation** — Step-by-step execution
- **Commands** — CLI commands with explanations
- **Verification** — How the result was tested
- **Real-world relevance** — Where this is used in cloud jobs
- **Key takeaway** — What I learned
